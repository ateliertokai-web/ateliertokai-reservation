# 予約データの自動バックアップ（無料・Google Apps Script）

毎日3時ごろと、毎月1日13時ごろ（解禁日の受付のあと）に、予約データを Google ドライブのスプレッドシート
「予約バックアップ」へ自動で保存します。実行した日時の名前のシートが1枚ずつ増え、60枚を超えると古いものから消えます。

あわせて **1時間ごと**に、ゴルフのイベントで参加者名がスペースを除いて完全一致する予約（同姓同名の可能性）を探し、
新しく見つかったときだけ `ateliertokai2027@gmail.com` にメールでお知らせします（お知らせ先は `backup.gs` の `NOTIFY_TO`）。

## 最初に1回だけやること（10分ほど）

> **必ず Firebase プロジェクトの持ち主（オーナー）の Google アカウントで**行ってください。

1. https://script.google.com を開き、「新しいプロジェクト」を作ります。名前は「予約バックアップ」などにします。
2. 左の歯車「プロジェクトの設定」を開き、「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェックを入れます。
3. 左の「エディタ」に戻り、次の2つを置き換えて保存します。
   - `appsscript.json` の中身 → このフォルダの `appsscript.json` の中身
   - `コード.gs` の中身 → このフォルダの `backup.gs` の中身
4. 上の関数の選び欄で **`backupNow`** を選び、「実行」を押します。
   - 初回は「承認が必要です」と出ます。「権限を確認」→ ご自身のアカウントを選ぶ →
     「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」。
     ご自身で作ったプログラムなので問題ありません。
   - Google ドライブに「予約バックアップ」というスプレッドシートができ、下の実行ログに件数が出れば成功です。
5. 関数の選び欄で **`setupTriggers`** を選び、「実行」を押します。これで自動バックアップと同姓同名の確認が始まります。
   - すでに設定済みの方も、`backup.gs` と `appsscript.json` を新しい内容に置き換えてから、もう一度 `setupTriggers` を実行してください（メール送信の許可を求められます）。

## そのあと
- **失敗したとき**は、Google から「スクリプトの失敗」のお知らせメールが届きます。
- **止めるとき**は `stopTriggers` を実行します。
- **すぐにとりたいとき**（解禁日の直後など）は `backupNow` を実行します。
- スプレッドシートには**お客様の個人情報**が入っています。**他の人と共有しないでください**。
- エラーで「403」と出るときは、Firebase の持ち主ではないアカウントで動かしている可能性があります。
